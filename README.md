# 6A-Math_DSE-MC

6A Maths DSE MC（45 題）成績查詢網站，包括 **DSE 2025**、**DSE 2023** 及 **DSE 2020** 三份試卷。

網址：https://kyopang2012-ux.github.io/6A-Math_DSE-MC/

## 登入

- **學生登入**：選擇學號，輸入個人密碼。每位學生只可查閱自己的成績，登入後可揀選 DSE 2025、DSE 2023 或 DSE 2020（預設打開 DSE 2023）。
- **教師登入**：輸入教師密碼，可查閱全班成績、等級分佈及各題正確率，並可篩選學生及以學生畫面預覽；同樣可切換三份試卷。

## 內容

- 學生：總對題、等級、全班排名、Set A（Level 3 題目）、Set B（Level 4 題目）及 Set C（Level 5+ 題目）對題數與錯題、全卷 45 題作答、需要溫習的題目（附全港答對率及全班答對率）
- 教師：全班總表、按等級／Set A／Set B／Set C 對題數／個別題目篩選、各題正確率、複製表格貼上 Excel

## 資料保護

`index.html` 內沒有任何明文姓名、成績或密碼。每位學生的資料以其個人密碼加密（PBKDF2-SHA256 600,000 次 + AES-256-GCM），全班資料以教師密碼另行加密；解密只在瀏覽器內進行。閒置 15 分鐘會自動登出。
