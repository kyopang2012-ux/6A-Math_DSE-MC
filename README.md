# 6A-Math_DSE-MC

6A Maths DSE 2020 MC（45 題）成績查詢網站。

網址：https://kyopang2012-ux.github.io/6A-Math_DSE-MC/

## 登入

- **學生登入**：選擇學號，輸入個人密碼。每位學生只可查閱自己的成績。
- **教師登入**：輸入教師密碼，可查閱全班成績、等級分佈及各題正確率，並可篩選學生及以學生畫面預覽。

## 內容

- 學生：總對題、等級、全班排名、Set A（Level 3 題目）及 Set B（Level 4 題目）對題數與錯題、全卷 45 題作答、需要溫習的題目
- 教師：全班總表、按等級／Set A／Set B 對題數／個別題目篩選、各題正確率、複製表格貼上 Excel

## 等級分界（總對題 / 45）

| 等級 | 題數 |
|---|---|
| Level 5** | 44–45 |
| Level 5* | 40–43 |
| Level 5 | 38–39 |
| Level 4 | 30–37 |
| Level 3 | 20–29 |
| Level 2 | 15–19 |
| 未達 Level 2 | 0–14 |

## 資料保護

`index.html` 內沒有任何明文姓名、成績或密碼。每位學生的資料以其個人密碼加密（PBKDF2-SHA256 600,000 次 + AES-256-GCM），全班資料以教師密碼另行加密；解密只在瀏覽器內進行。閒置 15 分鐘會自動登出。
